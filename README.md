# USO_IA
# Relatório de Uso de Inteligência Artificial — Mercado Santana

Este documento registra de forma transparente como as ferramentas de IA foram utilizadas pela Pessoa 1 no processo de documentação da Entrega 2.

## 1. Escopo de Utilização
A Inteligência Artificial foi utilizada estritamente para suporte de governança, formatação e revisão de textos:
* **Pessoa 1 (Documentação):** Uso de assistente de IA para estruturar as justificativas de modelagem, corrigir erros de digitação e organizar a apresentação dos relatórios no formato Markdown (`.md`).

## 2. Exemplos de Interações (Prompts, Respostas e Correções)

### Cenário 1: Correção Gramatical e Formatação Técnica
* **Prompt enviado pela Pessoa 1:** Envio dos rascunhos das justificativas de modelagem e das regras de normalização (1FN, 2FN e 3FN) solicitando correção de frases e concordância.
* **Resposta da IA:** O assistente reescreveu os parágrafos utilizando uma linguagem técnica padrão de mercado, corrigindo termos confusos e aplicando a sintaxe de listas em Markdown.
* **Correção Humana feita pela Pessoa 1:** Revisão minuciosa do texto gerado para garantir que os nomes das entidades criadas (como `Item_Venda`, `Movimentacao_Estoque` e `id_categoria`) correspondessem exatamente ao banco de dados do Mercado Santana.
